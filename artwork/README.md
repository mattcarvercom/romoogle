# Romoogle artwork

- `romoogle-logo.png` — 1600×700 dark CRT-style banner for the README and store listing.
- `romoogle-wordmark.png` — transparent pixel-art multicolor wordmark.
- `romoogle-icon.png` — 1024×1024 square icon (cartridge + magnifying glass).
- `romoogle-icon-512.png` — 512×512 store-friendly copy.

The wordmark uses Lato Black, pixelated for a retro edge, with a dark offset shadow. The
banner adds scanlines and the `INDEXED ROM SEARCH` tagline. The icon keeps the same
palette: a game cartridge with a multicolor label and a search magnifier.
